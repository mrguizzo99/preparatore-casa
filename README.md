# Preparatore Casa

Web App **iPhone-first** in stile **Apple Liquid Glass** per allenarsi a casa senza attrezzi (dimagrimento + forza parte superiore) e pianificare la cena del giorno successivo con caricamento diretto nel calendario iPhone.

## Come aggiungerla alla Home dell'iPhone
1. Apri il link GitHub Pages in **Safari** su iPhone.
2. Tocca **Condividi** (icona quadratino con freccia verso l'alto).
3. Scorri e seleziona **Aggiungi alla schermata Home**.
4. Conferma **Aggiungi**: l'app si aprirà a schermo intero con icona dedicata e salverà tutti i tuoi dati localmente sull'iPhone (nessun dato personale viene inviato o salvato online).
